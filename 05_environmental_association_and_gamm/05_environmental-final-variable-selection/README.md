# 05 Environmental Final Variable Selection

## Purpose

Define the parsimonious environmental predictor set after parsimony review.

## Input Files

1. `input/environmental_predictor_model_form_assessment.csv` - copied verbatim from workflow 04's seven-criterion model-form assessment output. It provides the independently calculated `selected_form`, `selected_k` and C1-C7 audit fields.
2. `input/preliminary_environmental_contribution.csv` - preliminary adjusted-model contribution table used only to apply the final parsimony rule.
3. `input/environmental_variables_selected_by_corr0.8_VIF10.csv` - selected-predictor modelling table generated by the previous screening workflow and copied into this module for local reproducibility.

## Scripts

- `scripts/define_parsimonious_environmental_predictors.py`: validates and propagates workflow 04's calculated model forms, then independently applies the predefined contribution-based parsimony rule. Validation requires exactly one assessment and one contribution row for each of the 14 screened predictors, accepted form labels, strict C1-C7 booleans, an empty `selected_k` for linear terms, and an integer `selected_k >= 4` for nonlinear terms. Each selected contribution value in `delta_deviance_explained`, `delta_AIC` and `full_model_term_p_value` must be numeric and finite (no `NaN`, `Inf` or `-Inf`), and p-values must lie between 0 and 1. It enforces the model-form contract in both directions: `selected_form == nonlinear` if and only if C1-C7 are all `TRUE`; a nonlinear row with any failed criterion and a linear row with all seven criteria passing are both rejected. Unrelated contribution rows are ignored.

## Expected Outputs

### Tables

1. `output/tables/parsimonious_environmental_predictors.csv`
   - Thirteen retained predictors with `selected_form`, `selected_k` and `model_form_source` provenance.
   - This is the direct input table from which workflow 06 constructs the GAMM formula dynamically.
2. `output/tables/parsimony_removed_terms.csv`
   - Audit table for terms removed during final variable selection.
   - Key columns: `variable`, `reason`, preliminary model-change fields and the P-value threshold used by the rule.

## Notes

This module documents the reduction from the screened environmental predictor set to the parsimonious model input. It does not refit the downstream GAMM. Model-form assessment occurs first in workflow 04 and is independent of the subsequent parsimony decision here.

## Method Rationale

This workflow keeps model-form selection, parsimony and GAMM fitting as distinct auditable decisions. The seven-criterion assessment currently classifies all 14 screened predictors as linear. `Precipitation of Warmest Quarter (Bio18)` is therefore first classified as linear, then removed because it has negative conditional deviance contribution and no statistical support (`p >= 0.05`). The resulting 13-row predictor table carries the calculated form metadata into workflow 06; the removal audit remains in `output/tables/parsimony_removed_terms.csv`.
