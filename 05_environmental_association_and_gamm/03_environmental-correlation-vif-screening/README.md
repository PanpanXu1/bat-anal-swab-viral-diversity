# 03 Environmental Correlation and Variance Inflation Factor (VIF) Screening

## Purpose

Validate the retained environmental predictor set against combined correlation and Variance Inflation Factor (VIF) criteria, and audit whether the retained set is a maximum-size feasible set.

## Input Files

- `input/standardized_environmental_variables_by_pool.csv`

Input provenance: this file is the standardized table generated by `../02_environmental-variable-standardization/output/tables/standardized_environmental_variables_by_pool.csv`. It is copied into this module's `input/` directory so the screening step can be run from this module while preserving the upstream relationship.

## Scripts

- `scripts/screen_environmental_correlation_vif.py`: calculates the candidate-predictor correlation matrix, validates the predefined retained predictor set, audits maximum-size correlation/VIF-feasible predictor combinations and exports the retained predictor set for downstream modelling.

## Expected Outputs

### Tables

1. `output/tables/all_candidate_spearman_correlation_matrix.csv`
   - Square Spearman correlation matrix for all candidate environmental predictors before filtering.
   - This table documents the correlation structure used for the threshold-based screening step.
2. `output/tables/selected_predictor_VIF_corr0.8_VIF10.csv`
   - VIF summary for predictors retained after correlation screening.
   - Key columns: `variable` and `VIF`.
3. `output/tables/selected_environmental_predictors.csv`
   - One-column list of predictor names retained by the correlation and VIF screening rules.
   - This compact list is used by the final-variable-selection workflow.
4. `output/tables/environmental_variables_selected_by_corr0.8_VIF10.csv`
   - Pool-level modelling table containing metadata, response variables and the retained environmental predictors.
   - This table is copied into the final GAMM workflow as a complete modelling input.
5. `output/tables/maximal_corr_vif_predictor_set_audit.csv`
   - Audit table documenting the largest predictor-set sizes evaluated under the combined criteria.
   - Key columns include `predictor_set_size`, `pairwise_corr_compatible_sets_checked`, `vif_qualified_sets`, `minimum_max_vif`, `retained_set_rank_by_lowest_max_vif` and `retained_set_is_maximum_size_vif_qualified_set`.
6. `output/tables/valid_14_predictor_sets_corr0.8_VIF10.csv`
   - All 14-predictor sets satisfying both the pairwise Spearman threshold and the VIF threshold.
   - This table records the max VIF ranking and marks the retained predictor set.

## Notes

The screening thresholds encoded in the file names are absolute Spearman correlation < 0.8 and VIF < 10. The module starts from the standardized table produced by the previous workflow. The retained 14-predictor set is not replaced by an alternative automatic selection during this step; instead, the script verifies and documents that it is a maximum-size feasible set under the combined criteria.

## Method Rationale

Correlation screening and VIF screening address complementary forms of predictor redundancy. The absolute Spearman correlation threshold removes strongly monotonic pairwise redundancy, while VIF evaluates multivariable collinearity among the retained predictors. The audit step constructs a compatibility graph using the pairwise correlation rule, checks candidate sets of sizes 16, 15 and 14, and calculates max VIF for each compatible set. This documents that no 16- or 15-predictor set satisfies both criteria, whereas the retained 14-predictor set is one of the feasible maximum-size sets and has the lowest max VIF among the feasible 14-predictor sets.
