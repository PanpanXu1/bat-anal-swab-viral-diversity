# 02 Bat Coronavirus Risk Score (CRS) Scatterplot

## Purpose

Plot the representative high-priority bat hosts in normalized coronavirus host-risk indicator space using the CRS values generated by the upstream prioritization workflow.

## Input Files

- `input/bat_crs_scatterplot_input.csv`: reduced plotting input containing the 12 selected hosts and the CRS-related numeric fields required for plotting.

This input is generated from `../01_bat-host-prioritization/output/tables/high_priority_bat_species_for_sdm.csv` by the upstream selection script. It is the plotting input for this workflow, not an independently curated species list.

## Scripts

- `scripts/plot_bat_crs_scatterplot.py`: reads the selected-host input table, plots CRS-related indicator positions and applies label placement rules to reduce label overlap.

## Expected Outputs

### Figures

1. `output/figures/bat_crs_scatterplot.pdf`
   - CRS scatterplot for the 12 representative high-priority hosts.
   - Point positions and colors are determined by the input numeric fields.
   - Label offsets are controlled by the plotting script only to improve readability.

## Method Rationale

The scatterplot displays the final data-driven coronavirus-priority host set from the upstream workflow rather than repeating the full CRS ranking table. Point positions come directly from the plotting input. Label placement is a figure-layout step used to reduce text overlap; it does not alter CRS values, normalized indicator values or species inclusion.
