# 03 Seasonal Species Accumulation and Extrapolation

## Purpose

Generate the seasonal species-accumulation and extrapolation panels, and generate the terrain-stratified accumulation panel with a separate iNEXT-based table of extrapolation metrics. The seasonal and terrain analyses address the same sampling-representation question but use different stratification variables.

## Input Files

1. `input/individual_records_with_season_and_terrain.csv` - individual-level host records with season, terrain and host species fields. This table drives the seasonal curves and the R/iNEXT calculation of terrain-specific extrapolation metrics.
2. `input/species_abundance_by_terrain.csv` - terrain-by-species abundance table used by the Python script to draw the terrain accumulation curves.
3. `input/terrain_inext_extrapolation_metrics.csv` - analysis-ready copy of the terrain metrics generated by `scripts/02_calculate_terrain_inext_extrapolation_metrics.R`. The Python terrain-plot script reads this copy so that the released Python batch can run without requiring an earlier R execution.

## Script Workflow

1. `scripts/01_plot_seasonal_species_accumulation_extrapolation.R`
   - Builds individual-based rarefaction and extrapolation curves separately for spring, summer, autumn and winter.
   - Uses the seasonal records in `input/individual_records_with_season_and_terrain.csv`.
   - Writes one PDF per season so the four seasonal panels can be checked independently.

2. `scripts/02_calculate_terrain_inext_extrapolation_metrics.R`
   - Uses `input/individual_records_with_season_and_terrain.csv` to calculate iNEXT-based terrain metrics.
   - Writes the numeric Gain (2N) and Slope (per 100) values to a table.
   - This script does not draw the terrain panel; it provides the numerical values reported in the terrain-panel legend.

3. `scripts/03_plot_terrain_species_accumulation_resampling.py`
   - Uses `input/species_abundance_by_terrain.csv` to draw simulation-based accumulation curves for the four terrain types.
   - Reads `input/terrain_inext_extrapolation_metrics.csv` for the iNEXT values reported in the legend.
   - The curve is based on Monte Carlo resampling means; the shaded band is based on resampling quantiles.
   - This script is separate from the iNEXT metric script so that the plotted accumulation envelope and the reported extrapolation metrics remain traceable to their respective methods.

## Expected Outputs

### Figures

1. `output/figures/seasonal_species_accumulation_spring.pdf` - individual-based spring accumulation/extrapolation curve.
2. `output/figures/seasonal_species_accumulation_summer.pdf` - individual-based summer accumulation/extrapolation curve.
3. `output/figures/seasonal_species_accumulation_autumn.pdf` - individual-based autumn accumulation/extrapolation curve.
4. `output/figures/seasonal_species_accumulation_winter.pdf` - individual-based winter accumulation/extrapolation curve.
5. `output/figures/terrain_species_accumulation_extrapolation.pdf` - terrain-stratified species accumulation curves with uncertainty envelopes.

### Tables

1. `output/tables/terrain_inext_extrapolation_metrics.csv`
   - `Terrain`: terrain category.
   - `N`: observed number of sampled individuals for that terrain.
   - `Observed_richness`: observed species richness at the observed sampling depth.
   - `Gain_to_2N`: expected additional richness when sampling effort is extrapolated from N to 2N.
   - `Slope_per_100`: local marginal gain in richness per 100 additional individuals near the observed sampling depth.

## Method Notes

The terrain figure and the terrain extrapolation metrics are generated by complementary methods. The plotted terrain curves use simulation-based individual resampling to visualize empirical richness accumulation under the observed sampling design. The Gain (2N) and Slope (per 100) values are calculated with iNEXT because it provides a standardized interpolation/extrapolation framework for quantifying expected richness gain beyond the observed sampling depth. Thus, the figure shows empirical accumulation behavior, whereas `output/tables/terrain_inext_extrapolation_metrics.csv` provides standardized extrapolation metrics reported in the legend.

The terrain panel and the extrapolation table are both generated from released inputs, and any legend values can be traced back to `output/tables/terrain_inext_extrapolation_metrics.csv`. Figure outputs are standardized to PDF.

The released `input/terrain_inext_extrapolation_metrics.csv` is byte-identical to the table generated by `scripts/02_calculate_terrain_inext_extrapolation_metrics.R` from the released individual records. If the source records or R/iNEXT settings are changed, rerun the R script and refresh this analysis-ready input copy before regenerating the terrain panel.
