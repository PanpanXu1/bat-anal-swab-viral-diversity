# 02 RdRp Amino Acid Identity Barplot

## Purpose

Summarize RdRp amino-acid identity categories in a PDF bar plot.

## Input Files

- `input/virus_order_amino_acid_identity_counts.csv`: RdRp amino-acid identity category counts by viral order used for plotting.

## Scripts

- `scripts/plot_rdrp_amino_acid_identity_barplot.py`: reads the categorized identity table and writes the PDF bar plot using the manuscript symbol labels, including `>=` and `<=` rendered as typographic comparison symbols in the figure.

## Expected Outputs

### Figures

1. `output/figures/rdrp_amino_acid_identity_barplot.pdf` - bar plot summarizing RdRp amino-acid identity categories.

## Method Rationale

The script starts from categorized amino-acid identity counts rather than raw alignments because this workflow reproduces the manuscript bar-plot layer, not the upstream sequence-alignment process. Category labels are generated by the script so comparison symbols are displayed consistently in the PDF output. Keeping the categorized count table makes the plotted values auditable without requiring readers to rerun the full RdRp alignment workflow.
