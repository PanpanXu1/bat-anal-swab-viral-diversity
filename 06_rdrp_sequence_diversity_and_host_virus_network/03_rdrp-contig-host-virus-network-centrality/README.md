# 03 RdRp Contig Host Virus Network Centrality

## Purpose

Plot the host-virus network centrality leaderboard derived from RdRp contig, host and virus classifications.

## Input Files

- `input/rdrp_contig_host_virus_network_centrality.csv`: centrality table used for the plotted leaderboard.

## Scripts

- `scripts/plot_rdrp_contig_host_virus_network_centrality.py`: reads the centrality table, applies the plotting order encoded in the input fields and writes the PDF centrality leaderboard.

## Expected Outputs

### Figures

1. `output/figures/centrality_leaderboard_portrait_clean_legend.pdf` - portrait-format centrality leaderboard with the legend and labels generated from the input table.

## Method Rationale

The centrality workflow starts from a prepared centrality table generated by the upstream network analysis. The plotting script uses this released table to reproduce the manuscript-ready centrality summary. This separation keeps the figure-generation step transparent because every plotted value is traceable to the local input table.
