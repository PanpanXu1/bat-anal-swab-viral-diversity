# Security and Sensitive Data Reporting

## Supported Scope

This repository contains analysis code and public analysis-ready input tables.
Security reporting mainly concerns accidental disclosure of sensitive data,
including precise cave roost coordinates, private sampling-site details or
controlled-access raw data.

## Reporting a Concern

Please do not open a public issue for sensitive data concerns. Email Dr.
Zhiqiang Wu at zqwu_lab@163.com with:

- a short description of the concern;
- the affected file path or workflow;
- whether the concern involves precise locality information, private data or
  software behavior.

## Public Issues

Public GitHub issues are appropriate for ordinary reproducibility problems,
documentation questions and non-sensitive script errors. They are not
appropriate for precise locality information or private sample metadata.

## Response

Sensitive data concerns will be reviewed as quickly as practical. If a public
file needs correction, the repository maintainers will remove or revise the
affected material and document the non-sensitive correction when appropriate.
